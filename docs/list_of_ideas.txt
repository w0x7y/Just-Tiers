Just-Tiers backlog, reviewed 2026-09-17

Future work, not supported features

1. Tab-list badges and chat integration. Current PlayerMixin only decorates world
   nametags. Each additional rendering path needs its own compatibility design.
2. Per-site toggles within All mode. Requires a config migration and a clear preview.
3. Runtime discovery of new gamemodes with fallback artwork. Unknown slugs currently
   need a registry, font and texture update in a new mod build.
4. Additional Minecraft release lines. CI/release automation already exists; broader
   support still needs version-specific dependencies, compilation and runtime checks.
5. Capture current configuration and lookup screenshots after the runtime checklist.
   The Modrinth description already includes a real nametag image; old placeholder
   screenshot comments were removed from the README.
6. Crosshair lookup keybind or a no-argument lookup command. The existing lookup screen
   now supports editing a name and retrying without leaving it.
7. A public tier-query API for other mods. Specify pending, unranked and failed results
   before exposing the cache's internal types.
8. Revisit the deferred lobby scan proposal. Its August design is archived, not shipped.

Already implemented

- Per-site debug report with clipboard copy, latency, errors and retry state.
- Pull-request/main build checks, wrapper validation, workflow lint and tagged releases
  to GitHub and Modrinth, with a separate Modrinth dry-run workflow.
- Resource contracts for icon mappings, textures and English translation keys.
- Keyboard-accessible pickers and player lookup, scrolling results, and visible save
  and refresh failures. Runtime validation remains in docs/runtime-smoke-test.md.
