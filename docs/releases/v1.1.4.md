## Just-Tiers 1.1.4 for Minecraft 26.2

This beta release reduces the mod's image sizes.

- Compressed the mod icon and all 32 gamemode textures. Their combined PNG size is
  now 24,809 bytes, down from 90,052 bytes before JAR compression.
- Kept the mod icon at 32x32 pixels and preserved all gamemode texture dimensions.
- Removed unused icon concepts and generation prompts from the repository.

Requires Java 25, Fabric Loader 0.19+, Fabric API for 26.2 and YACL 3.9.4+ for 26.2.
ModMenu is optional. Existing configuration files remain supported.
