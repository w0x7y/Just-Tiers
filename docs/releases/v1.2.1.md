## Just-Tiers 1.2.1 beta

This release fixes settings loading, network requests and keyboard focus, and draws
nametags with less work. It supports Minecraft 1.21.10, 1.21.11, 26.1, 26.1.1, 26.1.2,
26.2 and 26.3, with a separate JAR for each version.

- One invalid value in `config/justtiers.json` no longer resets every setting. That
  value falls back to its default and the rest of the file is kept. In site toggles,
  selected gamemodes and custom colors, only the affected site falls back. A file that
  is not valid JSON is copied to `justtiers.json.bak` before defaults load.
- A player's nametag badge is rebuilt only when your settings or that player's answers
  change, not every frame. The lookup screen also stops rebuilding its tooltips every
  frame.
- Player and Mojang requests give up after 20 seconds, and NovaTiers downloads after two
  minutes. Before, a server that stalled partway through a response could hold a request
  slot until the game closed.
- A NovaTiers refresh that lists no ranked players no longer replaces a populated index.
  It used to show every NovaTiers player as unranked.
- `/justtiers lookup` retries a site whose nametag request failed. Before, it could show
  the old failure until you looked the player up a second time.
- While a site is cooling down or paused, nametags stop retrying it every frame. A
  deferred request no longer resets the player's retry delay.
- A NovaTiers HTTP 503 without a Retry-After header no longer pauses downloads for 60
  seconds. NovaTiers now follows the same cooldown rule as the other sites.
- The palette controls stay available with nametag tiers off, because the palette also
  colors lookups and the download bar. Controls that only affect nametags say which
  switch turns them back on.
- The narrator announces which gamemode tile is the current selection.
- Resizing the window or changing the GUI scale keeps keyboard focus on the same lookup
  cell or gamemode tile.
- Hover highlights and tooltips in the gamemode picker and lookup screen use the same
  bounds as clicks. The bottom edge of the gamemode grid no longer highlights a tile
  that a click would miss.

Install the JAR for your exact Minecraft version with matching Fabric API and YACL.
Minecraft 1.21.10 and 1.21.11 require Java 21 and YACL 3.8.2 or newer. Minecraft
26.x requires Java 25 and YACL 3.9.4 or newer, except 26.3 which requires YACL
3.9.7 or newer and Fabric Loader 0.19.5 or newer. Other targets require Fabric
Loader 0.19 or newer. ModMenu remains optional. Server installation is unnecessary.
Existing settings carry over unchanged.
