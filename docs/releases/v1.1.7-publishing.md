release notes, proposed Modrinth version metadata, exact project and gallery update
payloads, and verification evidence. `build/release/just-tiers-1.1.7-review.zip`
contains the complete bundle.

   updates the summary, Markdown body and existing gallery captions. Page updates
   remain separate from version uploads.
5. Verify all seven uploaded versions, dependencies, release files and the live
   project copy. Report the release links. If an upload partially fails, rerun only
