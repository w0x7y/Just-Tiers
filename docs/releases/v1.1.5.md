## Just-Tiers 1.1.5

This beta release provides a separate mod JAR for Minecraft 1.21.11, 26.1, 26.1.1,
26.1.2, 26.2 and 26.3. Choose the JAR for your exact game version.

- Minecraft 1.21.11 requires Java 21, Fabric Loader 0.19 or newer, Fabric API for
  1.21.11 and YACL 3.8.2 or newer for 1.21.11.
- Minecraft 26.1, 26.1.1, 26.1.2 and 26.2 require Java 25, Fabric Loader 0.19 or newer,
  Fabric API for the game version and YACL 3.9.4 or newer for that version.
- Minecraft 26.3 requires Java 25, Fabric Loader 0.19.5 or newer, Fabric API for 26.3
  and YACL 3.9.7 or newer for 26.3. ModMenu remains optional on every target.

Settings screens preserve the previous active settings if saving fails and keep the
draft available for retry. Settings commands apply their changes to the current session
and warn if the file could not be saved. The lookup screen continues showing partial
results when one leaderboard fails, and a new lookup retries failed requests.

Existing configuration files remain supported. Nametags still affect world display;
tab-list and chat names are unchanged.
