## Just-Tiers 1.1.2 for Minecraft 26.2

This beta release fixes lookup reliability, config persistence and keyboard navigation.

- Malformed API responses now report failures instead of showing players as unranked.
- Cache invalidation ignores obsolete retry callbacks, and overlapping NovaTiers refreshes
  share one download. Failed refreshes retain the last usable index.
- Config saves preserve the previous file on failure, show a retry action and keep active
  settings unchanged. Cancel and Undo remain safe after a failed save.
- Gamemode pickers support keyboard activation and focused previews. Back no longer selects
  a tile, and previews fit narrow columns.
- Player lookup supports editing and retrying names, scrolling small windows, and keyboard
  access to result cells and leaderboard links. Failed skin requests can be retried.
- Refresh feedback, disabled-control explanations and palette colors are consistent with
  the current settings. Documentation describes actual network use and failure behavior.
- Automated checks include icon/translation contracts and Linux/Windows builds. Release
  workflows now mark beta releases as GitHub prereleases.

Local verification: 428 unit/resource tests and 26 in-client assertions passed. See the
[runtime checklist](https://github.com/w0x7y/Just-Tiers/blob/main/docs/runtime-smoke-test.md)
for the tested scope and remaining environment-dependent checks.

Requires Java 25, Fabric Loader 0.19+, Fabric API for 26.2 and YACL 3.9.4+ for 26.2.
ModMenu is optional. Existing configuration files remain supported.
