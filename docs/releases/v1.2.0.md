## Just-Tiers 1.2.0 beta

This release supports Minecraft 1.21.10, 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2 and
26.3, with a separate JAR for each version.

- With several sites enabled, turn on Prefer selected gamemodes, or run
  `/justtiers preferselected`, to show each site's selected gamemode. A player
  without a placement there shows their best placement on that site. With one site
  enabled, its selection always applies, and the command says so.
- Choose any site's gamemode with `/justtiers gamemode <site> <slug>`. The command
  warns when the selection will not show under the current site settings.
- Gamemodes a site adds before a mod update appear in nametags and lookups with a
  name derived from the site and no icon, after the known gamemodes. They cannot be
  selected until a mod update registers them.
- The lookup screen shows up to eight recent names as buttons, most recent first,
  and `/justtiers lookup` tab completion offers them. They are kept in memory for
  the current game session only and never saved.
- Other Fabric client mods can read Just-Tiers' answers through the tier-query API
  described in [docs/api.md](../api.md). It follows the nametag and site switches
  and never sends offline-mode or NPC UUIDs to the leaderboards.
- When a new lookup leaves a row with fewer cells, keyboard focus moves to that
  row's last remaining cell instead of being lost.

Install the JAR for your exact Minecraft version with matching Fabric API and YACL.
Minecraft 1.21.10 and 1.21.11 require Java 21 and YACL 3.8.2 or newer. Minecraft
26.x requires Java 25 and YACL 3.9.4 or newer, except 26.3 which requires YACL
3.9.7 or newer and Fabric Loader 0.19.5 or newer. Other targets require Fabric
Loader 0.19 or newer. ModMenu remains optional. Server installation is unnecessary.
Existing settings carry over unchanged.
