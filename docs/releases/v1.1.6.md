## Just-Tiers 1.1.6 beta

This release improves lookup reliability for all six supported Minecraft versions:
1.21.11, 26.1, 26.1.1, 26.1.2, 26.2 and 26.3.

- Keep last-known successful placements visible during refresh and temporary outages,
  with a finite stale grace period. Lookup tooltips show answer age and refresh status.
- Bound concurrent and queued requests per source, prioritize explicit lookups over
  background nametag work, and honor server Retry-After cooldowns.
- Validate NovaTiers bulk records before publishing an immutable index. Malformed or
  conflicting player records remain unavailable rather than appearing unranked.
- Bound per-player cache and retry retention, and reuse immutable nametag settings to
  reduce repeated allocation.
- Keep each lookup session's placements and freshness together. A later refresh with
  identical placements cannot reset an older session's answer age.
- Centralize request admission and successful name/skin lookup retention, including
  retry when failure is observed before the eviction callback completes.

Use the JAR for your exact Minecraft version with its matching Fabric API and YACL.
The required Java versions and dependency versions are unchanged from 1.1.5.
