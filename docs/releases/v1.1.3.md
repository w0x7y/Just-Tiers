## Just-Tiers 1.1.3 for Minecraft 26.2

This beta release introduces the new bracketed JT icon.

- Yellow J, cyan T and purple brackets represent the three supported leaderboards and
  the mod's nametag badges.
- The icon is packaged with the mod and declared in Fabric metadata for ModMenu.

Requires Java 25, Fabric Loader 0.19+, Fabric API for 26.2 and YACL 3.9.4+ for 26.2.
ModMenu is optional. Existing configuration files remain supported.
