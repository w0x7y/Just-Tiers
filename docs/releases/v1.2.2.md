## Just-Tiers 1.2.2

Every gamemode icon is new. All 43 icons are original pixel art drawn for Just-Tiers.
They replace the PvPTiers, PvPHQ and SubTiers icons that earlier versions took from
TierTagger. The NovaTiers and PvPHQ Spear icons are redrawn in the same style.

- Gamemodes that play the same way share one icon across sites, so an axe badge looks the
  same on PvPTiers, PvPHQ and NovaTiers. The badge color still shows which site it is from.
- Icons keep their own colors when you change the palette, as before.
- Nothing else changes. Settings, commands and network behavior match 1.2.1.

Install the JAR for your exact Minecraft version with matching Fabric API and YACL.
Minecraft 1.21.10 and 1.21.11 require Java 21 and YACL 3.8.2 or newer. Minecraft
26.x requires Java 25 and YACL 3.9.4 or newer, except 26.3 which requires YACL
3.9.7 or newer and Fabric Loader 0.19.5 or newer. Other targets require Fabric
Loader 0.19 or newer. ModMenu remains optional. Server installation is unnecessary.
Existing settings carry over unchanged.
