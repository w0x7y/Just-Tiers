## Just-Tiers 1.2.3

Gamemode icons now use Minecraft's built-in textures directly instead of packaged PNGs, so
they match your active resource packs and reload cleanly with them.

- Most gamemodes reference built-in `minecraft:` textures directly in `justtiers:icons`.
- Five icons (`pot`, `debuff`, `speed`, `spear_mace`/`spearmace` and `elytraspear`) are
  composited in memory at font-load time from your active resource packs. A resource pack can
  still override any of them by providing `assets/justtiers/textures/composite/<name>.png`.
- On older Minecraft targets missing a required vanilla texture, such as `netherite_spear.png`
  on 1.21.10, affected composite icons fall back to a two-letter pixel-text badge (`SM`, `ES`)
  generated in memory.
- No custom gamemode PNGs are packaged in the JAR. Settings, commands, palettes and network
  behavior match 1.2.2.

Install the JAR for your exact Minecraft version with matching Fabric API and YACL.
Minecraft 1.21.10 and 1.21.11 require Java 21 and YACL 3.8.2 or newer. Minecraft
26.x requires Java 25 and YACL 3.9.4 or newer, except 26.3 which requires YACL
3.9.7 or newer and Fabric Loader 0.19.5 or newer. Other targets require Fabric
Loader 0.19 or newer. ModMenu remains optional. Server installation is unnecessary.
Existing settings carry over unchanged.
