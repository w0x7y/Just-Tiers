## Just-Tiers 1.1.7 beta

PvPTiers replaces the discontinued MCTiers integration, and PvPHQ joins SubTiers
and NovaTiers. This release supports Minecraft 1.21.10, 1.21.11, 26.1, 26.1.1,
26.1.2, 26.2 and 26.3, with a separate JAR for each version.

- Use PvPTiers in the former MCTiers yellow and PvPHQ in gray `#D2D2D2`.
- Enable or disable each site independently in configuration or with
  `/justtiers site <site> [true|false]`. The old display-mode selector and
  `/justtiers mode` command are replaced by these toggles.
- With several sites enabled, show each site's best placement. With exactly one
  enabled, prefer its selected gamemode and fall back to its best placement.
  Disabling all four sites hides nametag tiers. Explicit player lookups still
  include all four sites.
- Support PvPHQ's 11 gamemodes and middle divisions, such as MT3. Middle divisions
  rank between high and low divisions of the same tier. Inactive placements are
  not treated as retired, and peak placements are ignored.
- Migrate existing MCTiers gamemodes and custom colors to PvPTiers. Old single-site
  display modes preserve that choice; the old all-sites mode enables all four.
- Update lookup rows, configuration previews, color palettes, icons and diagnostics
  for all four sites and 43 supported gamemodes.
- Add Minecraft 1.21.10 compatibility alongside the six existing targets.

Install the JAR for your exact Minecraft version with matching Fabric API and YACL.
Minecraft 1.21.10 and 1.21.11 require Java 21 and YACL 3.8.2 or newer. Minecraft
26.x requires Java 25 and YACL 3.9.4 or newer, except 26.3 which requires YACL
3.9.7 or newer and Fabric Loader 0.19.5 or newer. Other targets require Fabric
Loader 0.19 or newer. ModMenu remains optional. Server installation is unnecessary.
